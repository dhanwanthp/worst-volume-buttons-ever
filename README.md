# worst-volume-buttons-ever
This repository contains the design for the terrible volume buttons 

The aim of this repository is to serve as a hub for the **most terrible volume button designs** you can come up with.
Create a branch and add your design with a relevant README.md file on its description and design.

Primary contributors: @dhanwanthp, @fargamer18 and @kushal
